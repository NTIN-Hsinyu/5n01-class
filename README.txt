# 五護101班｜班級資訊平台

本網站為五護101班之班級資訊與管理平台，整合班級公告、小考與作業提醒、近期行程、課表、導師信箱及常用連結等功能，提供班級成員集中查看班務資訊。

網站採用 Google 帳號登入，並透過 Firebase Authentication 與 Firestore 進行身分驗證及權限管理。

## 主要功能

### 📢 班級公告
- 查看班級公告與重要訊息
- 公告可依類別呈現
- 支援重要公告置頂
- 公告可選擇同步建立為待辦事項

### ✅ 小考、作業與待辦
- 建立小考、作業及一般待辦事項
- 設定日期與截止時間
- 支援每週、每兩週及每月重複事項
- 學生可於自己的裝置標記「已完成」
- 首頁自動顯示近期重要待辦

### 📅 班級行事曆
- 串接 Google Calendar
- 顯示班級近期行程
- 提供完整行事曆入口

### 📚 班級課表
- 顯示週一至週五第 1–8 節課程
- 導師可直接於網站編輯課程與教室
- 課表資料儲存於 Firestore

### 💌 導師信箱
- 學生可選擇匿名或具名留言
- 具名留言可與老師持續對話
- 老師有新留言、學生有老師新回覆時，信箱圖示會顯示提示
- 匿名留言不儲存學生識別資訊，亦不提供回覆功能

### 👥 班級成員與權限管理
系統依不同身分提供相應操作權限：

| 功能 | 導師 | 班級幹部 | 小老師 | 一般學生 |
| --- | :---: | :---: | :---: | :---: |
| 查看公告 | ✓ | ✓ | ✓ | ✓ |
| 新增公告 | ✓ | ✓ | ✕ | ✕ |
| 修改／刪除公告 | 全部 | 自己建立 | ✕ | ✕ |
| 查看待辦 | ✓ | ✓ | ✓ | ✓ |
| 新增待辦 | ✓ | ✓ | ✓ | ✕ |
| 修改／刪除待辦 | 全部 | 自己建立 | 自己建立 | ✕ |
| 編輯班級課表 | ✓ | ✕ | ✕ | ✕ |
| 班級成員管理 | ✓ | ✕ | ✕ | ✕ |
| 座位表管理 | ✓ | ✕ | ✕ | ✕ |

「小老師」在系統中仍屬學生身分，僅額外取得小考、作業與待辦的管理權限。

## 登入與安全機制

- 使用 Google 帳號登入
- 僅限班級白名單中的帳號建立班級成員資料
- 使用 Firestore Security Rules 控制資料存取權限
- 一般學生無法自行變更為導師、幹部或小老師
- 班級成員資料與權限資料儲存於 Firestore，不直接寫入公開網頁原始碼
- 匿名導師信箱不儲存寄件者姓名、學號、Email 或 UID

## 技術架構

- HTML / CSS / JavaScript
- GitHub Pages
- Firebase Authentication
- Cloud Firestore
- Google Calendar API
- Progressive Web App (PWA)
- Service Worker

## PWA

網站支援加入手機主畫面，可作為班級資訊入口使用。

更新網站版本後，若手機仍顯示舊版內容，可能與 PWA / Service Worker 快取有關，可重新載入網站或清除網站資料後再開啟。

## 注意事項

本系統僅供班級內部班務與教學用途。

請勿將學生個人資料、登入資訊、Firebase 管理憑證或其他敏感資訊直接提交至公開 GitHub Repository。
